# DeNoise 用户行为 × 产品响应矩阵

> 这份文档回答一个问题：**用户在专注期间可能做什么，DeNoise 分别怎么接？**
> 每条都对应到代码里的真实路径，路演被追问时可以当场指出来。

---

## 0. 总原则：四层响应，越往下越贵

| 层 | 手段 | 成本 | 触发条件 |
|---|---|---|---|
| L1 | 域名名单硬匹配 | 0 token，< 1ms | 页面 URL 一出现就能判定 |
| L2 | 内容启发式（标题/搜索词/娱乐词） | 0 token，< 5ms | 混合型站点，L1 判不了 |
| L3 | LLM 语义判别 | 1 次小请求（~1s） | L2 拿不准 |
| L4 | 多模态看图复核 | 1 次带图请求 | 强力模式下的灰区标签页 |

**核心取舍：能不上模型就不上模型。** 抖音、淘宝这类页面上限就在 L1，B 站、YouTube、Google 搜索走 L2 → L3，只有「标题一片空白 / 纯图片 PDF / 内网文档」才升到 L4。

对应代码：`src/shared/domainRules.ts`（L1/L2）、`src/background/judgeEngine.ts`（L3/L4）。

## 1. 打开一个页面

| 用户行为 | 判定层 | DeNoise 响应 | 用户看到什么 |
|---|---|---|---|
| 打开抖音 / 快手 / 淘宝 / 微博 / 爱奇艺 | L1 `direct_park` | 直接收进 `💤 暂存休息舱`，后台 discard 释放内存 | 标签组自动折叠，弹一条极简提示 |
| 打开 GitHub / arXiv / LeetCode / ChatGPT / Claude / DeepSeek / AI Studio | L1 `direct_learning` | 直接放行，按类目自动编组 | 标签自动染上「💻 代码与文档」等分组色 |
| 打开 B 站 / YouTube / 知乎 / Google 搜索 / 百度 / CSDN | L1 `content_check` | 进 L2：看标题 + 搜索词 + 娱乐关键词 | 判定快时无感，判定慢时页面照常可读 |
| 打开任意 `.pdf` | L1 | 直通「📄 文献与笔记」 | 永不被折叠 |
| 打开没见过的站 | L1 `unknown` | 进 L2/L3 语义判别 | 默认放行，只在明显偏离时才提醒 |

**为什么这样分层**：抖音这类站点的 URL 本身就是信号，花 token 去判断「这条视频是不是学习」是浪费；而 B 站同一个域名下既有一小时算法课也有搞笑鬼畜，必须看内容。

## 2. 刷推荐流（不换页，只是往下滚）

| 用户行为 | DeNoise 响应 |
|---|---|
| 首页推荐流里出现无关卡片 | 毛玻璃 `blur(11px)` 虚化 + 灰化，卡片右上角给 `[ 👁 临时查看 ]` `[ 📌 标为资料 ]` |
| 卡片与任务相关 | 打上 `🎯 任务相关` 极简微标，不虚化 |
| 页面动态插入新卡片（无限滚动） | `MutationObserver` + 300ms 防抖，增量判定，不重扫全页 |
| 热搜榜 / 侧边推荐位 / 弹窗 | 站点适配器直接移除或折叠成静音条，不走模型 |

**关键设计**：虚化而不是删除。用户永远可以点「临时查看」，这一下点击本身就是「我确实想看」的信号，不打断。

---

## 3. 新开一个标签页（分心的主要入口）

| 用户行为 | 模式 | DeNoise 响应 |
|---|---|---|
| 新开页与任务相关 | 全部 | 自动归入对应学习分组，刷新「最近学习页」指针 |
| 新开页明显无关 | 🌱 温和 | 只在页面内虚化推荐流，**不动标签页** |
| 新开页明显无关 | ⚖️ 标准 | 折叠进 `💤 暂存休息舱`（可点回来） |
| 新开页明显无关 | 🔥 强力 | 截图存档 → 关闭 → 进《🛡️ 防误杀黑匣子》 |
| 新开页灰区（15%~60% 分） | 🔥 强力 | 先截图，多模态模型看图复核；仍存疑 → 只折叠不关闭 |

**防误杀底线**：任何「拿不准」的页面，最终动作都是「折叠」而不是「关闭」。关闭动作必须同时写入黑匣子并保存关闭前截图。

---

## 4. 在当前页待久了（偏航）

| 用户行为 | DeNoise 响应 |
|---|---|
| 在一个低相关页面停留 ≥ 2s | 顶部弹出温和提醒条，显示相关性分数与理由 |
| 强力模式下相关性 < 25% | 直接弹全屏护航卡（含「确认偏离 / 仅切回 / 误判放行」三个出口） |
| 用户点「确认偏离」 | 收进 `💤 暂存休息舱` 或无关标签组，切回上一个学习页 |
| 用户点「误判，标为资料」 | 加入本场白名单 + 归入对应学习类目，本场不再提醒该页 |
| 用户点「✕ 暂时收起」 | 只在当前 URL 收起，刷新或换页后重新评估 |

**为什么留三个出口**：偏航判定一定会有错，产品必须让「我确实是误判」成为一次点击就能表达的动作，而不是逼用户去设置页关功能。

## 5. 专注结束

| 用户行为 | DeNoise 响应 |
|---|---|
| 倒计时归零 | 自动结算，弹《降噪结算小票》 |
| 手动点「结束专注」 | 同上 |
| 小票内容 | SNR、纯净度评级、虚化/清除/接管/保护/召回五项明细、AI 专注复盘 |
| 点「恢复全部」 | 休息舱解组 + 黑匣子页面按原 URL 重新打开 |
| 点「导出图片」 | Canvas 离屏绘制 2x 高清 PNG（含 AI 复盘段落），直接下载 |
| 点「复制 Markdown」 | 生成可直接贴进 Notion / 飞书的复盘块 |

**AI 复盘怎么来**：`stopFocusSession` 先落历史记录，再异步调一次轻量 LLM（DeepSeek V4.1-Flash，关闭思考链，`max_tokens ≈ 320`）生成 badge / summary / highlights；失败则用本地启发式模板兜底，小票永远有内容，不会空着。

## 6. 长期使用

| 用户行为 | DeNoise 响应 |
|---|---|
| 每次专注结束 | 写入 `FocusHistoryRecord`（最多保留 200 条） |
| 打开插件弹窗 | 展示今日 / 本周 / 本月 / 今年专注分钟数与次数、连续天数 |
| 本周累计达标 | 进度条满格，解锁「7 天 Pro」激励文案 |
| 未达标 | 显示「再专注 N 分钟解锁」，把目标拆成可见的小步 |

数据全部在 `chrome.storage.local`，没有账号、没有服务端、不上传。

---

## 7. 断网 / 没配 Key / 模型挂了

| 情况 | DeNoise 响应 |
|---|---|
| 用户没填任何 API Key | 全程走本地词簇 + 域名规则，功能可用，弹窗提示「本地降级模式」 |
| 请求超时或报错 | `judgeBatch` 捕获异常，整批回退到本地语义判别，不阻塞页面 |
| DeepSeek 新模型未开通 | 自动回落 `deepseek-chat` 兼容别名，用户无感 |
| Ollama 本地节点 | 免 Key，只要节点地址；拉不到模型列表时允许手填 |

**现场演示保障**：即使会场断网，L1 + L2 两层仍然完整可用，降噪、编组、休息舱、黑匣子、小票全部能跑。

---

## 8. 一句话总结（路演可用）

> DeNoise 不是「猜你在干什么」，而是「按你能接受的代价，逐级升级判断」。
> 域名能判的绝不调模型，模型能判的绝不关页面，关掉的页面一定能捞回来。
